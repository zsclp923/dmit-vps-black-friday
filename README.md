## 黑五价背后的四个变量，拿这张清单去核对页面

同一个“黑五价”，最后掏的钱可能差一倍以上。下面四个变量决定了标价和真实支出之间的距离，每一项都能在结账页或条款里查到，DMIT 页面同样适用。

**一、首期价和续费价是不是一回事**

VM6 Networks 今年的黑五方案是英国机房年付减 55%、两年付减 60%，2 核 4GB、60GB NVMe、5TB 月流量做到 £27/年，价格确实低。但它的条款写得很清楚：优惠仅适用于首个计费周期，后续按正常价格续费，并非循环折扣。第二年账单会跳回原价。

DMIT 公开的折扣码多标注为“循环折扣（recurring）”，意思是续费时同一折扣继续生效，这是两者在长期成本上的实质差别。核对方法很简单：结账页输入码后看折扣类型写的是 recurring 还是一次性。年付特价档要单独看，特价本身不等于循环折扣。

**二、优惠之间能不能叠加**

RakSmart 这轮双 11 加黑五，VPS 秒杀价 $2.99/月起（硅谷 2 核 2G、50G HDD、国际 BGP、5Gbps 带宽、10TB 流量），但秒杀产品不可叠加代理商折扣、不可用优惠券、不可用预充值赠送金，满减券与折扣券也互斥，每单限用一张。低价是真低价，代价是所有其他优惠同时作废。

DMIT 的折扣码按机房和产品线分别发放，EB 一条、Pro 一条、T1 一条，互相之间不通用。拿 Pro 的码去开 T1 不会生效，反过来也一样。下单前先确认目标套餐属于哪条线，再找对应的码，别在结账页反复试。

**三、库存放量和限购**

RakSmart 的秒杀库存按美国时间 0 点（北京时间 16 点）开放，每日限量 20 台，单个用户当月限购 5 台，30 天内新注册用户每款限购 1 台。NoslaCloud 的黑五套餐则是每款每账户限购 1 台。这类规则决定了你能不能等到“再看看”的第二天。

DMIT 的年付特价档同理，属于限量补货的档位，不是随时都能买到。真要买 WEE 或 MALIBU，看到价格合适就下单，比守着一个不确定的补货时间更实际。

**四、IP 性质和流量计费口径**

NoslaCloud 的圣何塞和东京机房用的是德国广播 IPv4，不是本地原生 IP，做需要本地 IP 属性的业务会踩坑；它的套餐全部双向流量计费、共享带宽，流量用尽后限速。这些信息写在页面里，但很容易被“1Gbps 带宽”这种大字盖过去。

DMIT 部分套餐的流量标注为 BIDI（双向），1000GB 双向意味着上传下载合计 1000GB，实际可用量是单向计费的一半。带宽写 10Gbps 的是共享端口，不等于随时能跑满。核对时只看两个字段：流量是单向还是双向，端口是共享还是独享。

## 按场景选档：五种常见需求分别对应哪一档

**只放一个静态站、反代、监控探针。** 1 核 1GB 够用，选 LAX.Pro.WEE（$39.9/年）或 LAX.Pro.TINY（$9.99/月）。静态页面的瓶颈在带宽不在 CPU，500GB 月流量对日均几百 IP 的站点绰绰有余。这一档也是试线路成本最低的入口。

**WordPress、小型 CMS、带插件的站点。** 从 LAX.Pro.Pocket（$14.90/月，1 核 2GB、40GB SSD、1.5TB）起步。PHP 加 MySQL 一起吃内存，1GB 机器装完面板和数据库就所剩无几，Pocket 的 2GB 是这条线的及格线。日访问量上千后升 STARTER（$29.90/月），2 核 2GB、80GB、3TB 流量，端口也从 4Gbps 升到 10Gbps。

**跑 Docker 多容器、自建数据库、CI 构建。** 看内存和磁盘，不看核心数。LAX.Pro.MINI（$58.88/月，4 核 4GB、80GB、5TB）是这一档的起点，MEDIUM（$168.88/月，4 核 8GB、160GB、14TB）适合数据库和缓存一起吃内存的场景。构建任务吃的是磁盘 IO，SSD 容量比核心数更值得加钱。

**访客主要在欧美，国内只是自己登录后台。** 不必为回国线路付溢价。Tier 1 的 STARTER 在洛杉矶、香港、东京同价 $12.90/月（1 核 2GB、40GB、4000GB 流量），走的是普通国际骨干，欧美访问质量与 Pro 的差距远小于价差。洛杉矶 Pro 卖 $29.90/月 的那部分钱，花在了回国链路上。

**国内访问为主，后台操作要顺手。** 线路优先级高于核心数。同样预算下，香港 Pro 的物理距离最近但单价最高（TINY $39.90/月），洛杉矶 Pro 是折中方案。这一档不要为了省几美元把 2 核降成 1 核，卡顿主要来自链路抖动，不是 CPU。

**长期跑低带宽、大流量的服务。** DMIT 有不限流量档，uMINI 起步是 2 核 2GB、40GB、30Mbps 独享带宽，$239.99/月，往上还有 50Mbps、100Mbps、200Mbps 三档。起步价约为常规 STARTER 档的 8 倍，只有明确需要固定带宽不限量时才值得考虑。

## 这几种情况，DMIT 不是好选择

**预算卡在 $3/月以内。** DMIT 最便宜的月付是 $9.99，年付摊下来也要 $3.3/月左右。这个预算段 RakSmart 的硅谷秒杀更直接：2 核 2G、50G HDD、国际 BGP、5Gbps 带宽、10TB 流量，$2.99/月。代价是 HDD 磁盘、秒杀不可叠加任何券、续费价格以结算页为准、每日限量 20 台。能接受这些限制，它就是更便宜的选择。

**要 CN2 线路但预算在 300 元/年附近。** NoslaCloud 洛杉矶 1 核 1GB、20GB NVMe、500GB 月流量、200Mbps，¥349/年，三网优化、年付续费同价。需要留意的是它采用动态路由调度，入向流量达到规定阈值时去程可能临时切换普通线路，共享带宽也不保证峰值。买之前跑一遍 Looking Glass 比看参数有用。

**需要独立服务器或裸金属。** DMIT 只做 KVM 虚拟化的 VPS，没有独服产品线。这一档需求要去看 RakSmart 的 E3-1230、16G、1T HDD 独服（$29.9/月起，大陆优化 VIP、100Mbps 不限流量）或裸机云（E5-2620、32G、1T HDD，$45.9/月起）。
